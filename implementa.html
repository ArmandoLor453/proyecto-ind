Maquetado y Diseño

El maquetado y diseño web es el proceso de crear la estructura visual y funcional de una página web utilizando HTML, CSS y JavaScript.

Elementos principales:

  • HTML (HyperText Markup Language): Estructura del contenido
  • CSS (Cascading Style Sheets): Estilos y presentación visual
  • JavaScript: Interactividad y funcionalidad dinámica
  • Responsive Design: Adaptación a diferentes dispositivos
  • UI/UX: Interfaz de usuario y experiencia de usuario
Principios de diseño web:
• Simplicidad: Diseños limpios y fáciles de navegar
• Consistencia: Elementos uniformes en todas las páginas
• Jerarquía visual: Orden de importancia en elementos
• Accesibilidad: Diseño inclusivo para todos los usuarios
• Performance: Carga rápida y optimizada

Bases de Datos y Fundamentos

Una base de datos es un conjunto organizado de información estructurada, almacenada electrónicamente en un sistema informático.

Conceptos fundamentales:

  • Dato: Información básica (nombre, edad, dirección)
  • Tabla: Conjunto de datos organizados en filas y columnas
  • Registro: Fila de una tabla (un elemento completo)
  • Campo: Columna de una tabla (un atributo específico)
  • Clave: Identificador único de un registro
Tipos de Bases de Datos:
• Relacionales (SQL): MySQL, PostgreSQL, Oracle, SQL Server
• No Relacionales (NoSQL): MongoDB, Redis, Cassandra
• En memoria: Redis, Memcached
• Orientadas a objetos: db4o, ObjectDB

Modelado de Bases de Datos (Entidad-Relación)

El modelo Entidad-Relación (ER) es una técnica de diseño que permite representar gráficamente la estructura de una base de datos.

Componentes del modelo ER:

  • Entidad: Objeto o concepto del mundo real (Cliente, Producto, Pedido)
  • Atributo: Característica de una entidad (nombre, precio, fecha)
  • Relación: Asociación entre entidades (Cliente REALIZA Pedido)
  • Cardinalidad: Número de instancias que participan (1:1, 1:N, N:M)
Ejemplo de relaciones:
• Uno a Uno (1:1): Una persona tiene un pasaporte
• Uno a Muchos (1:N): Un cliente puede tener varios pedidos
• Muchos a Muchos (N:M): Estudiantes pueden tomar varias materias, y cada materia tiene varios estudiantes

Conceptos Base en Base de Datos

Terminología esencial:

Concepto Definición Ejemplo

Query Consulta para obtener datos SELECT * FROM usuarios

Normalización de Bases de Datos

La normalización es el proceso de organizar datos para reducir redundancia y mejorar la integridad.

Formas Normales:

  • Primera Forma Normal (1FN): Eliminar grupos repetitivos, cada campo debe contener valores atómicos
  • Segunda Forma Normal (2FN): Cumplir 1FN + eliminar dependencias parciales (todos los atributos dependen de la clave completa)
  • Tercera Forma Normal (3FN): Cumplir 2FN + eliminar dependencias transitivas
Beneficios de la normalización:
✓ Reduce redundancia de datos
✓ Mejora la integridad de datos
✓ Facilita el mantenimiento
✓ Optimiza el espacio de almacenamiento
✓ Previene anomalías de actualización

Empaquetado de Software

El empaquetado de software es el proceso de preparar una aplicación para su distribución e instalación.

Formatos comunes:

  • .exe: Windows executables
  • .msi: Windows Installer packages
  • .deb: Debian/Ubuntu packages
  • .rpm: Red Hat/Fedora packages
  • .jar: Java Archive
  • .apk: Android Application Package
  • .dmg: macOS Disk Image
Elementos de un paquete:
• Archivos ejecutables
• Bibliotecas y dependencias
• Archivos de configuración
• Documentación
• Scripts de instalación/desinstalación
• Metadatos (versión, autor, licencia)

SQL DDL (Data Definition Language)

DDL son comandos SQL utilizados para definir y modificar la estructura de la base de datos.

Comandos principales:

  • CREATE: Crear objetos (tablas, vistas, índices)
  • ALTER: Modificar estructura existente
  • DROP: Eliminar objetos
  • TRUNCATE: Eliminar todos los registros de una tabla
-- Crear una base de datos
CREATE DATABASE mi_empresa;

-- Usar la base de datos
USE mi_empresa;

-- Crear una tabla
CREATE TABLE empleados (
  id INT PRIMARY KEY AUTO_INCREMENT,
  nombre VARCHAR(100) NOT NULL,
  departamento VARCHAR(50),
  salario DECIMAL(10, 2),
  fecha_contratacion DATE
);

-- Modificar tabla
ALTER TABLE empleados ADD COLUMN email VARCHAR(100);

-- Eliminar tabla
DROP TABLE empleados;

CREATE TABLE con Definición de Columnas y Tipos de Datos

El comando CREATE TABLE define la estructura de una nueva tabla especificando columnas y tipos de datos.

Tipos de datos comunes en SQL:

Tipo Descripción Ejemplo
INT Números enteros 1, 100, -50
VARCHAR(n) Cadena de texto variable 'Juan', 'Hola Mundo'
DECIMAL(p,s) Números decimales 1500.50, 99.99
DATE Fecha 2026-01-05
BOOLEAN Verdadero/Falso TRUE, FALSE
TEXT Texto largo Descripciones extensas
CREATE TABLE productos (
  producto_id INT PRIMARY KEY AUTO_INCREMENT,
  nombre VARCHAR(100) NOT NULL,
  descripcion TEXT,
  precio DECIMAL(10, 2) NOT NULL,
  stock INT DEFAULT 0,
  disponible BOOLEAN DEFAULT TRUE,
  fecha_creacion DATE,
  categoria_id INT,
  FOREIGN KEY (categoria_id) REFERENCES categorias(id)
);

Operadores Utilizados en Programación

Los operadores son símbolos que realizan operaciones sobre variables y valores.

Tipos de operadores:

Tipo Operadores Ejemplo
Aritméticos +, -, *, /, % 5 + 3 = 8
Comparación ==, !=, <, >, <=, >= x > 10
Lógicos &&, ||, ! (x > 5) && (y < 10)
Asignación =, +=, -=, *=, /= x += 5
Incremento/Decremento ++, -- i++, --j
Ejemplos en Java:
int a = 10, b = 5;
int suma = a + b; // 15
int resta = a - b; // 5
int multiplicacion = a * b; // 50
int division = a / b; // 2
int modulo = a % b; // 0

boolean resultado = (a > b) && (a != 0); // true

Sentencias Cíclicas

Las sentencias cíclicas permiten repetir un bloque de código múltiples veces.

Principales estructuras:

// CICLO FOR
for (int i = 0; i < 10; i++) {
  System.out.println("Iteración: " + i);
}

// CICLO WHILE
int i = 0;
while (i < 10) {
  System.out.println("Iteración: " + i);
  i++;
}

// CICLO DO-WHILE
int i = 0;
do {
  System.out.println("Iteración: " + i);
  i++;
} while (i < 10);

// FOREACH (para colecciones)
int[] numeros = {1, 2, 3, 4, 5};
for (int num : numeros) {
  System.out.println(num);
}

Programación Orientada a Objetos (POO)

La POO es un paradigma de programación basado en objetos que contienen datos y métodos.

Principios fundamentales:

  • Encapsulamiento: Ocultar detalles internos del objeto
  • Herencia: Reutilizar código mediante clases derivadas
  • Polimorfismo: Múltiples formas de un mismo método
  • Abstracción: Representar conceptos esenciales
Ventajas de la POO:
✓ Reutilización de código
✓ Modularidad y organización
✓ Mantenimiento más sencillo
✓ Escalabilidad
✓ Modelado del mundo real

¿Qué es una Clase en POO?

Una clase es una plantilla o molde que define atributos y métodos comunes a un grupo de objetos.

// Ejemplo de una clase en Java
public class Persona {
  // Atributos (variables de instancia)
  private String nombre;
  private int edad;
  private String email;

     // Constructor
  public Persona(String nombre, int edad, String email) {
    this.nombre = nombre;
    this.edad = edad;
    this.email = email;
  }

     // Métodos (comportamiento)
  public void saludar() {
    System.out.println("Hola, mi nombre es " + nombre);
  }

     // Getters y Setters
  public String getNombre() {
    return nombre;
  }

     public void setNombre(String nombre) {
    this.nombre = nombre;
  }
}

¿Cuál es el Método Principal en un Programa en Java?

El método main() es el punto de entrada de cualquier aplicación Java. Es donde comienza la ejecución del programa.

public class MiPrograma {
  public static void main(String[] args) {
    // Aquí comienza la ejecución del programa
    System.out.println("¡Hola, Mundo!");
    
    // Crear objetos y ejecutar lógica
    Persona persona = new Persona("Juan", 25, "juan@email.com");
    persona.saludar();
  }
}
Componentes del método main:
• public: Accesible desde cualquier lugar
• static: Pertenece a la clase, no requiere instancia
• void: No retorna ningún valor
• main: Nombre obligatorio del método
• String[] args: Parámetros de línea de comandos

¿Qué es un IDE?

IDE significa Integrated Development Environment (Entorno de Desarrollo Integrado). Es un software que proporciona herramientas completas para programar.

Componentes de un IDE:

  • Editor de código: Con resaltado de sintaxis y autocompletado
  • Compilador/Intérprete: Para ejecutar el código
  • Depurador (Debugger): Para encontrar y corregir errores
  • Administrador de proyectos: Organiza archivos y recursos
  • Control de versiones: Integración con Git
IDEs populares:
• Java: IntelliJ IDEA, Eclipse, NetBeans
• Python: PyCharm, Visual Studio Code
• C/C++: Visual Studio, Code::Blocks
• Web: Visual Studio Code, WebStorm
• Android: Android Studio

Sintaxis de Ciclo FOR

El ciclo FOR es una estructura de control que permite repetir un bloque de código un número específico de veces.

// Sintaxis básica:
for (inicialización; condición; incremento) {
  // Código a repetir
}

// Ejemplo 1: Contar del 1 al 10
for (int i = 1; i <= 10; i++) {
  System.out.println(i);
}

// Ejemplo 2: Recorrer un array
String[] nombres = {"Ana", "Carlos", "María"};
for (int i = 0; i < nombres.length; i++) {
  System.out.println("Nombre: " + nombres[i]);
}

// Ejemplo 3: Ciclo descendente
for (int i = 10; i >= 1; i--) {
  System.out.println(i);
}

// Ejemplo 4: Incremento de 2 en 2
for (int i = 0; i <= 20; i += 2) {
  System.out.println("Número par: " + i);
}

¿Qué es un Gestor de Base de Datos?

Un Sistema Gestor de Base de Datos (DBMS - Database Management System) es un software que permite crear, gestionar y administrar bases de datos.

Funciones principales:

  • Almacenamiento: Guardar datos de forma organizada
  • Consulta: Recuperar información mediante queries
  • Actualización: Modificar datos existentes
  • Seguridad: Control de acceso y permisos
  • Respaldo: Backup y recuperación de datos
  • Integridad: Mantener consistencia de datos
Gestores populares:
• MySQL: Open source, muy popular para web
• PostgreSQL: Open source, robusto y avanzado
• Oracle Database: Empresarial, potente
• Microsoft SQL Server: Para entornos Windows
• MongoDB: Base de datos NoSQL
• SQLite: Ligero, embebido en aplicaciones

Primary Key y Foreign Key

Primary Key (Clave Primaria):

Es un campo o conjunto de campos que identifica de forma única cada registro en una tabla.

  • Debe ser único (no se puede repetir)
  • No puede ser NULL
  • Solo puede haber una primary key por tabla
  • Generalmente se usa un campo ID con auto-incremento

Foreign Key (Clave Foránea):

Es un campo que establece una relación entre dos tablas, referenciando la primary key de otra tabla.

  • Mantiene la integridad referencial
  • Previene datos huérfanos
  • Puede ser NULL (si la relación es opcional)
  • Una tabla puede tener múltiples foreign keys
-- Tabla con PRIMARY KEY
CREATE TABLE clientes (
  cliente_id INT PRIMARY KEY AUTO_INCREMENT,
  nombre VARCHAR(100),
  email VARCHAR(100)
);

-- Tabla con FOREIGN KEY
CREATE TABLE pedidos (
  pedido_id INT PRIMARY KEY AUTO_INCREMENT,
  fecha DATE,
  total DECIMAL(10, 2),
  cliente_id INT,
  FOREIGN KEY (cliente_id) REFERENCES clientes(cliente_id)
);
Ejemplo de relación:
Si tenemos un cliente con ID = 1, podemos crear múltiples pedidos con cliente_id = 1, estableciendo así una relación 1:N (un cliente puede tener muchos pedidos).
