1. ¿Qué es un campo en álgebra?

Un campo es una estructura algebraica formada por un conjunto no vacío con dos operaciones: suma y multiplicación, que cumplen los axiomas de cierre, asociatividad, conmutatividad, existencia de elementos neutros, existencia de inversos y la distributividad de la multiplicación sobre la suma.

Ejemplos de campos:
• Los números reales (ℝ)
• Los números racionales (ℚ)
• Los números complejos (ℂ)

2. Los números reales y sus propiedades

El conjunto de los reales (ℝ) incluye naturales, enteros, racionales e irracionales. Es denso (entre dos reales siempre hay otro), ordenado (tiene relación ≤) y completo (todo conjunto acotado y no vacío tiene supremo).

  • Propiedades de orden: si a ≤ b y b ≤ c ⇒ a ≤ c (transitividad).
  • Valor absoluto: |a| ≥ 0 y |a| = √(a²).
  • Intervalos: [a,b], (a,b), [a,b), (a,b].
  • Densidad: ∀a
Clasificación: ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ; irracionales como √2, π, e no son racionales.

3. Enteros, racionales y naturales

ℕ (Naturales): 0, 1, 2, 3, ...
ℤ (Enteros): ..., −3, −2, −1, 0, 1, 2, 3, ...
ℚ (Racionales): { p/q | p, q ∈ ℤ, q ≠ 0 }
ℝ (Reales): ℚ ∪ irracionales (π, √2, e, ...)

Los racionales tienen expansión decimal finita o periódica. Los irracionales tienen expansión infinita no periódica. Los enteros incluyen negativos, cero y positivos; los naturales suelen comenzar en 0 o 1 según convención.

Ejemplos: −4 ∈ ℤ; 3/5 ∈ ℚ; √2 ∈ ℝ\ℚ; 0 ∈ ℕ (convención común).

4. ¿Qué son los números primos?

Un primo es un entero mayor que 1 con solo dos divisores positivos: 1 y él mismo. Todo entero n>1 se descompone de forma única como producto de primos (Teorema Fundamental de la Aritmética).

  • 2 es el único primo par.
  • Si n no tiene divisores ≤ √n, entonces es primo.
Primos pequeños: 2, 3, 5, 7, 11, 13, 17, 19...

5. Definición de inverso aditivo

El inverso aditivo de a es −a, tal que a + (−a) = 0. En ℝ, cada número tiene inverso aditivo y es único. Geométricamente, es el punto simétrico respecto a 0 en la recta real.

inv+(7) = −7; inv+(−3) = 3; inv+(0) = 0.

6. Cociente de potencias en la misma base

Si a ≠ 0 y m, n ∈ ℤ, entonces am / an = am−n. Esta regla se extiende a exponentes negativos: a−k = 1/ak.

  • a0 = 1 para a ≠ 0.
  • No se define 00 en aritmética elemental.
25 / 23 = 22 = 4; x7 / x2 = x5.

7. ¿Qué son los signos de agrupación?

Se usan para organizar y clarificar el orden de las operaciones:

  • Paréntesis ( )
  • Corchetes [ ]
  • Llaves { }
  • Barra de fracción y radical también actúan como agrupadores.
{ 2 · [3 + (4 − 1)] } = { 2 · [3 + 3] } = 12

8. Jerarquía de operaciones

Orden estándar (PEMDAS):

  1. Paréntesis y agrupación
  2. Exponentes y raíces
  3. Multiplicación y división (izquierda a derecha)
  4. Suma y resta (izquierda a derecha)
  • El signo menos puede ser unario (−a) o binario (a−b); respeta la jerarquía.
  • La barra de fracción agrupa numerador y denominador.
6 + 2 × (3² − 1) = 6 + 2 × 8 = 22

9. ¿Por qué es un campo y no solo un conjunto?

Un conjunto solo colecciona elementos. Un campo añade estructura: define suma y multiplicación y exige axiomas. Por eso ℝ no es solo “un conjunto de números”, sino un campo con propiedades que permiten operaciones coherentes.

Comparación:
• Conjunto: elementos sin operaciones.
• Grupo (suma): cierre, asociativa, neutro, inverso.
• Anillo: suma (grupo abeliano) y producto asociativo, distributivo.
• Campo: anillo conmutativo donde todo elemento ≠ 0 tiene inverso multiplicativo.
