1. Programación Orientada a Objetos (POO)

La Programación Orientada a Objetos es un paradigma de programación que organiza el código en objetos que contienen datos (atributos) y funciones (métodos).

Pilares fundamentales de la POO:

  • Encapsulamiento: Ocultar los detalles de implementación y proteger los datos
  • Herencia: Reutilizar código mediante clases padre e hijas
  • Polimorfismo: Múltiples formas de un mismo método
  • Abstracción: Representar conceptos esenciales sin detalles de implementación
Ventajas de POO:
✓ Código más organizado y mantenible
✓ Reutilización de código
✓ Modelado natural del mundo real
✓ Facilita el trabajo en equipo
✓ Mayor escalabilidad

2. Clase, Objeto e Instancia

Definiciones:

  • Clase: Es una plantilla o molde que define las características (atributos) y comportamientos (métodos) que tendrán los objetos
  • Objeto: Es una instancia concreta de una clase, con valores específicos
  • Instancia: Es el proceso de crear un objeto a partir de una clase
// Definición de una CLASE
public class Auto {
  // Atributos
  private String marca;
  private String modelo;
  private int año;
  private String color;

     // Constructor
  public Auto(String marca, String modelo, int año, String color) {
    this.marca = marca;
    this.modelo = modelo;
    this.año = año;
    this.color = color;
  }

     // Métodos
  public void arrancar() {
    System.out.println("El auto está arrancando...");
  }

     public void frenar() {
    System.out.println("El auto está frenando...");
  }
}

// Crear OBJETOS (INSTANCIAS) de la clase Auto
Auto miAuto = new Auto("Toyota", "Corolla", 2023, "Rojo");
Auto tuAuto = new Auto("Honda", "Civic", 2024, "Azul");

// Usar los objetos
miAuto.arrancar(); // Salida: El auto está arrancando...
tuAuto.frenar(); // Salida: El auto está frenando...
Analogía: Si la clase "Auto" es el plano arquitectónico de un coche, los objetos "miAuto" y "tuAuto" son los coches reales construidos a partir de ese plano.

3. Encapsulamiento y Abstracción

Encapsulamiento:

Es el mecanismo que oculta los detalles internos de una clase y protege los datos mediante modificadores de acceso.

Modificadores de acceso en Java:

  • private: Solo accesible dentro de la misma clase
  • public: Accesible desde cualquier lugar
  • protected: Accesible en la misma clase, subclases y mismo paquete
  • default (sin modificador): Accesible en el mismo paquete
public class CuentaBancaria {
  // Atributos privados (encapsulados)
  private String titular;
  private double saldo;
  private String numeroCuenta;

     // Constructor
  public CuentaBancaria(String titular, String numeroCuenta) {
    this.titular = titular;
    this.numeroCuenta = numeroCuenta;
    this.saldo = 0.0;
  }

     // Métodos públicos (getters y setters)
  public double getSaldo() {
    return saldo;
  }

     public void depositar(double cantidad) {
    if (cantidad > 0) {
      saldo += cantidad;
      System.out.println("Depósito exitoso. Nuevo saldo: " + saldo);
    }
  }

     public void retirar(double cantidad) {
    if (cantidad > 0 && cantidad <= saldo) {
      saldo -= cantidad;
      System.out.println("Retiro exitoso. Nuevo saldo: " + saldo);
    }
  }
}

Abstracción:

Es el proceso de ocultar los detalles de implementación y mostrar solo la funcionalidad esencial al usuario.

Ejemplo de abstracción: Cuando usas un cajero automático, solo presionas botones para retirar dinero. No necesitas saber cómo funciona internamente el sistema bancario, la verificación de saldo, o la comunicación con el banco. Eso está abstraído para ti.

5. Herencia y Tipos de Herencia

La herencia es un mecanismo que permite crear nuevas clases basadas en clases existentes, reutilizando código y estableciendo relaciones jerárquicas.

Tipos de Herencia:

  • Herencia Simple: Una clase hija hereda de una sola clase padre
  • Herencia Multinivel: Una clase hereda de otra que a su vez hereda de otra (A → B → C)
  • Herencia Jerárquica: Múltiples clases heredan de una misma clase padre
  • Herencia Múltiple: (No soportada directamente en Java, pero se puede lograr con interfaces)
// Clase PADRE (Superclase)
public class Animal {
  protected String nombre;
  protected int edad;

     public Animal(String nombre, int edad) {
    this.nombre = nombre;
    this.edad = edad;
  }

     public void comer() {
    System.out.println(nombre + " está comiendo");
  }

     public void dormir() {
    System.out.println(nombre + " está durmiendo");
  }
}

// Clase HIJA 1 (Subclase) - Herencia Simple
public class Perro extends Animal {
  private String raza;

     public Perro(String nombre, int edad, String raza) {
    super(nombre, edad); // Llamar al constructor del padre
    this.raza = raza;
  }

     public void ladrar() {
    System.out.println(nombre + " está ladrando: ¡Guau guau!");
  }
}

// Clase HIJA 2 - Herencia Jerárquica
public class Gato extends Animal {
  private String color;

     public Gato(String nombre, int edad, String color) {
    super(nombre, edad);
    this.color = color;
  }

     public void maullar() {
    System.out.println(nombre + " está maullando: ¡Miau!");
  }
}

// USO:
Perro miPerro = new Perro("Max", 3, "Labrador");
miPerro.comer(); // Heredado de Animal
miPerro.ladrar(); // Propio de Perro

Gato miGato = new Gato("Luna", 2, "Blanco");
miGato.dormir(); // Heredado de Animal
miGato.maullar(); // Propio de Gato
Palabra clave "super":
• Se usa para llamar al constructor de la clase padre
• También para acceder a métodos y atributos del padre
• Debe ser la primera línea en el constructor hijo

6. Polimorfismo y Tipos de Polimorfismo

El polimorfismo permite que un objeto tome múltiples formas. Permite que diferentes clases respondan de manera distinta al mismo mensaje.

Tipos de Polimorfismo:

1. Polimorfismo en tiempo de compilación (Sobrecarga - Overloading):

Múltiples métodos con el mismo nombre pero diferentes parámetros.

public class Calculadora {
  // Mismo nombre, diferentes parámetros
  public int sumar(int a, int b) {
    return a + b;
  }

     public int sumar(int a, int b, int c) {
    return a + b + c;
  }

     public double sumar(double a, double b) {
    return a + b;
  }
}

Calculadora calc = new Calculadora();
calc.sumar(5, 3); // Llama al primer método → 8
calc.sumar(5, 3, 2); // Llama al segundo método → 10
calc.sumar(5.5, 3.2); // Llama al tercer método → 8.7

2. Polimorfismo en tiempo de ejecución (Sobrescritura - Overriding):

Una clase hija redefine un método de la clase padre.

class Figura {
  public void dibujar() {
    System.out.println("Dibujando una figura");
  }
}

class Circulo extends Figura {
  @Override
  public void dibujar() {
    System.out.println("Dibujando un círculo ⭕");
  }
}

class Cuadrado extends Figura {
  @Override
  public void dibujar() {
    System.out.println("Dibujando un cuadrado ⬛");
  }
}

// Polimorfismo en acción:
Figura f1 = new Circulo();
Figura f2 = new Cuadrado();

f1.dibujar(); // Salida: Dibujando un círculo ⭕
f2.dibujar(); // Salida: Dibujando un cuadrado ⬛
Ventajas del Polimorfismo:
✓ Código más flexible y extensible
✓ Reduce duplicación de código
✓ Facilita el mantenimiento
✓ Permite escribir código más genérico

8. Operadores en Java

1. Operadores Aritméticos:

Operador Descripción Ejemplo Resultado
+ Suma 5 + 3 8
- Resta 5 - 3 2
* Multiplicación 5 * 3 15
/ División 10 / 2 5
% Módulo (residuo) 10 % 3 1

2. Operadores de Comparación:

Operador Descripción Ejemplo
== Igual a 5 == 5 → true
!= Diferente de 5 != 3 → true
> Mayor que 5 > 3 → true
< Menor que 5 < 3 → false
>= Mayor o igual que 5 >= 5 → true
<= Menor o igual que 3 <= 5 → true

3. Operadores Lógicos:

Operador Descripción Ejemplo
&& AND lógico (5 > 3) && (2 < 4) → true
|| OR lógico (5 > 3) || (2 > 4) → true
! NOT lógico !(5 > 3) → false

4. Operadores de Asignación:

int x = 10; // Asignación simple
x += 5; // x = x + 5 → x = 15
x -= 3; // x = x - 3 → x = 12
x *= 2; // x = x * 2 → x = 24
x /= 4; // x = x / 4 → x = 6
x %= 4; // x = x % 4 → x = 2

5. Operadores de Incremento/Decremento:

int i = 5;
i++; // Post-incremento: primero usa, luego incrementa → i = 6
++i; // Pre-incremento: primero incrementa, luego usa → i = 7
i--; // Post-decremento: primero usa, luego decrementa → i = 6
--i; // Pre-decremento: primero decrementa, luego usa → i = 5

9. Condiciones en Java

Las estructuras condicionales permiten ejecutar diferentes bloques de código según se cumplan ciertas condiciones.

1. IF - ELSE IF - ELSE:

int edad = 18;

if (edad < 13) {
  System.out.println("Eres un niño");
} else if (edad >= 13 && edad < 18) {
  System.out.println("Eres un adolescente");
} else if (edad >= 18 && edad < 65) {
  System.out.println("Eres un adulto");
} else {
  System.out.println("Eres un adulto mayor");
}

2. SWITCH:

int dia = 3;
String nombreDia;

switch (dia) {
  case 1:
    nombreDia = "Lunes";
    break;
  case 2:
    nombreDia = "Martes";
    break;
  case 3:
    nombreDia = "Miércoles";
    break;
  case 4:
    nombreDia = "Jueves";
    break;
  case 5:
    nombreDia = "Viernes";
    break;
  case 6:
    nombreDia = "Sábado";
    break;
  case 7:
    nombreDia = "Domingo";
    break;
  default:
    nombreDia = "Día inválido";
}

System.out.println("Hoy es: " + nombreDia);

3. Operador Ternario:

int edad = 20;
String mensaje = (edad >= 18) ? "Eres mayor de edad" : "Eres menor de edad";
System.out.println(mensaje);

// Equivalente a:
if (edad >= 18) {
  mensaje = "Eres mayor de edad";
} else {
  mensaje = "Eres menor de edad";
}

10. Ciclo FOR

El ciclo FOR es una estructura de control que permite repetir un bloque de código un número determinado de veces.

Sintaxis:

for (inicialización; condición; actualización) {
  // Código a repetir
}

Ejemplos:

// Ejemplo 1: Contar del 1 al 10
for (int i = 1; i <= 10; i++) {
  System.out.println("Número: " + i);
}

// Ejemplo 2: Números pares del 0 al 20
for (int i = 0; i <= 20; i += 2) {
  System.out.println("Par: " + i);
}

// Ejemplo 3: Contar regresivo
for (int i = 10; i >= 1; i--) {
  System.out.println(i);
}
System.out.println("¡Despegue! 🚀");

// Ejemplo 4: Recorrer un array
String[] frutas = {"Manzana", "Banana", "Naranja", "Uva"};
for (int i = 0; i < frutas.length; i++) {
  System.out.println("Fruta " + (i+1) + ": " + frutas[i]);
}

// Ejemplo 5: For-Each (para colecciones)
for (String fruta : frutas) {
  System.out.println("Me gusta la " + fruta);
}

// Ejemplo 6: Tabla de multiplicar
int numero = 5;
for (int i = 1; i <= 10; i++) {
  System.out.println(numero + " x " + i + " = " + (numero * i));
}
Partes del ciclo FOR:
• Inicialización: Se ejecuta una vez al inicio (int i = 0)
• Condición: Se evalúa antes de cada iteración (i < 10)
• Actualización: Se ejecuta después de cada iteración (i++)
• Cuerpo: Código que se repite

12. Diferencia entre Primitivos y Compuestos

Tipos de Datos Primitivos:

Son los tipos de datos más básicos del lenguaje. Almacenan valores simples directamente en memoria.

  • Características:
    • Almacenan un solo valor
    • Ocupan un tamaño fijo de memoria
    • Se almacenan en el stack (pila)
    • Se comparan por valor
    • No pueden ser null
    • Tienen valor por defecto (0, false, etc.)
  • 8 tipos primitivos en Java: byte, short, int, long, float, double, char, boolean

Tipos de Datos Compuestos (Referencia):

Son tipos de datos complejos que pueden contener múltiples valores y comportamientos.

  • Características:
    • Almacenan referencias a objetos en memoria
    • Tamaño variable
    • Se almacenan en el heap (montículo)
    • Se comparan por referencia
    • Pueden ser null
    • Valor por defecto: null
  • Ejemplos: String, Arrays, Clases, Interfaces, Collections
// PRIMITIVOS
int numero = 10; // Almacena directamente el valor 10
double precio = 19.99; // Almacena directamente 19.99
boolean activo = true; // Almacena directamente true
char letra = 'A'; // Almacena directamente 'A'

// COMPUESTOS (Referencia)
String nombre = "Juan"; // Almacena referencia al objeto String
int[] numeros = {1, 2, 3}; // Almacena referencia al array
Persona p = new Persona(); // Almacena referencia al objeto Persona

// Comparación:
int a = 5;
int b = 5;
System.out.println(a == b); // true (compara valores)

String s1 = new String("Hola");
String s2 = new String("Hola");
System.out.println(s1 == s2); // false (compara referencias)
System.out.println(s1.equals(s2)); // true (compara contenido)
Aspecto Primitivos Compuestos
Almacenamiento Valor directo Referencia a objeto
Memoria Stack (pila) Heap (montículo)
Tamaño Fijo Variable
Null No puede ser null Puede ser null
Métodos No tienen métodos Tienen métodos

13. ¿Qué es un Acumulador?

Un acumulador es una variable que se utiliza para almacenar y sumar valores progresivamente dentro de un ciclo. Su propósito es ir acumulando (sumando) valores.

Características:

  • Se inicializa generalmente en 0 (o el valor neutro de la operación)
  • En cada iteración se le suma un nuevo valor
  • Al final del ciclo contiene la suma total
  • Se usa para calcular totales, promedios, sumas, etc.
// Ejemplo 1: Acumular suma de números del 1 al 10
int acumulador = 0; // Inicializar en 0
for (int i = 1; i <= 10; i++) {
  acumulador = acumulador + i; // También: acumulador += i;
  System.out.println("Suma parcial: " + acumulador);
}
System.out.println("Suma total: " + acumulador); // 55

// Ejemplo 2: Acumular el precio total de productos
double[] precios = {19.99, 25.50, 10.00, 45.75};
double totalCompra = 0.0; // Acumulador

for (double precio : precios) {
  totalCompra += precio;
}
System.out.println("Total a pagar: $" + totalCompra); // $101.24

// Ejemplo 3: Calcular promedio con acumulador
int[] calificaciones = {85, 90, 78, 92, 88};
int sumaCalificaciones = 0; // Acumulador

for (int cal : calificaciones) {
  sumaCalificaciones += cal;
}
double promedio = (double) sumaCalificaciones / calificaciones.length;
System.out.println("Promedio: " + promedio); // 86.6

// Ejemplo 4: Acumulador para concatenar strings
String[] palabras = {"Hola", "mundo", "desde", "Java"};
String frase = ""; // Acumulador de texto

for (String palabra : palabras) {
  frase += palabra + " ";
}
System.out.println(frase); // "Hola mundo desde Java "
Diferencia entre acumulador y contador:
• Acumulador: Suma valores variables (suma += valor)
• Contador: Suma siempre de 1 en 1 (contador++)

14. ¿Qué es un Contador?

Un contador es una variable que se utiliza para llevar la cuenta del número de veces que ocurre algo, incrementándose en una cantidad fija (generalmente 1) en cada iteración.

Características:

  • Se inicializa generalmente en 0
  • Se incrementa en 1 cada vez (contador++)
  • Se usa para contar eventos, iteraciones, elementos, etc.
  • Útil para llevar control de repeticiones
// Ejemplo 1: Contar números pares
int contador = 0;
for (int i = 1; i <= 100; i++) {
  if (i % 2 == 0) {
    contador++; // Incrementar el contador
  }
}
System.out.println("Hay " + contador + " números pares"); // 50

// Ejemplo 2: Contar palabras en un texto
String texto = "Java es un lenguaje de programación";
String[] palabras = texto.split(" ");
int contadorPalabras = palabras.length;
System.out.println("Número de palabras: " + contadorPalabras); // 6

// Ejemplo 3: Contar aprobados y reprobados
int[] calificaciones = {85, 55, 90, 45, 78, 92, 50, 88};
int aprobados = 0;
int reprobados = 0;

for (int cal : calificaciones) {
  if (cal >= 60) {
    aprobados++;
  } else {
    reprobados++;
  }
}
System.out.println("Aprobados: " + aprobados); // 5
System.out.println("Reprobados: " + reprobados); // 3

// Ejemplo 4: Contar vocales en un texto
String frase = "Programación en Java";
int contadorVocales = 0;

for (int i = 0; i < frase.length(); i++) {
  char c = Character.toLowerCase(frase.charAt(i));
  if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') {
    contadorVocales++;
  }
}
System.out.println("Vocales encontradas: " + contadorVocales);
Resumen:
• Contador: variable++ (incremento fijo de 1)
• Acumulador: variable += valor (suma valores variables)
• Ambos son fundamentales en programación para llevar control de datos

15. ¿Qué es un Bucle y cuáles son los más usados en Java?

Un bucle (o ciclo) es una estructura de control que permite repetir un bloque de código múltiples veces mientras se cumpla una condición.

Los 3 bucles más usados en Java:

1. Bucle FOR:

Se usa cuando se conoce el número exacto de iteraciones.

// Sintaxis:
for (inicialización; condición; actualización) {
  // Código a repetir
}

// Ejemplo:
for (int i = 0; i < 5; i++) {
  System.out.println("Iteración: " + i);
}
// Salida: 0, 1, 2, 3, 4

2. Bucle WHILE:

Se usa cuando no se conoce el número de iteraciones, pero sí la condición de parada.

// Sintaxis:
while (condición) {
  // Código a repetir
}

// Ejemplo:
int i = 0;
while (i < 5) {
  System.out.println("Iteración: " + i);
  i++;
}
// Salida: 0, 1, 2, 3, 4

// Ejemplo práctico: Validar entrada
Scanner sc = new Scanner(System.in);
int numero = 0;
while (numero <= 0) {
  System.out.println("Ingrese un número positivo:");
  numero = sc.nextInt();
}
System.out.println("Número válido: " + numero);

3. Bucle DO-WHILE:

Similar al while, pero garantiza al menos una ejecución porque evalúa la condición al final.

// Sintaxis:
do {
  // Código a repetir
} while (condición);

// Ejemplo:
int i = 0;
do {
  System.out.println("Iteración: " + i);
  i++;
} while (i < 5);
// Salida: 0, 1, 2, 3, 4

// Ejemplo práctico: Menú
int opcion;
do {
  System.out.println("=== MENÚ ===");
  System.out.println("1. Jugar");
  System.out.println("2. Configuración");
  System.out.println("3. Salir");
  opcion = sc.nextInt();
} while (opcion != 3);

4. For-Each (para colecciones):

String[] nombres = {"Ana", "Carlos", "María", "Juan"};
for (String nombre : nombres) {
  System.out.println("Hola, " + nombre);
}
Bucle Cuándo usarlo Característica
FOR Número exacto de iteraciones Más compacto
WHILE No se sabe cuántas iteraciones Evalúa condición antes
DO-WHILE Al menos una ejecución garantizada Evalúa condición después
FOR-EACH Recorrer colecciones/arrays Más simple y legible

16. Funciones en la Clase Math, cómo son y cómo se implementan en Java

La clase Math en Java proporciona métodos estáticos para realizar operaciones matemáticas comunes.

Funciones más utilizadas:

// 1. POTENCIA y RAÍZ
double potencia = Math.pow(2, 3); // 2^3 = 8.0
double raiz = Math.sqrt(16); // √16 = 4.0
double raizCubica = Math.cbrt(27); // ∛27 = 3.0

// 2. VALOR ABSOLUTO
int absoluto = Math.abs(-10); // 10
double absDouble = Math.abs(-15.5); // 15.5

// 3. MÁXIMO y MÍNIMO
int maximo = Math.max(10, 25); // 25
int minimo = Math.min(10, 25); // 10

// 4. REDONDEO
double num = 3.7;
long redondeado = Math.round(num); // 4
double arriba = Math.ceil(num); // 4.0 (redondea hacia arriba)
double abajo = Math.floor(num); // 3.0 (redondea hacia abajo)

// 5. NÚMEROS ALEATORIOS
double aleatorio = Math.random(); // Número entre 0.0 y 1.0
// Número aleatorio entre 1 y 100:
int aleatorio1a100 = (int)(Math.random() * 100) + 1;

// 6. FUNCIONES TRIGONOMÉTRICAS
double angulo = Math.toRadians(45); // Convertir grados a radianes
double seno = Math.sin(angulo);
double coseno = Math.cos(angulo);
double tangente = Math.tan(angulo);

// 7. EXPONENCIAL y LOGARITMOS
double exp = Math.exp(2); // e^2
double log = Math.log(10); // Logaritmo natural
double log10 = Math.log10(100); // Logaritmo base 10 = 2.0

// 8. CONSTANTES
double pi = Math.PI; // 3.141592653589793
double e = Math.E; // 2.718281828459045

Ejemplos prácticos:

// Ejemplo 1: Calcular hipotenusa
public static double calcularHipotenusa(double cateto1, double cateto2) {
  return Math.sqrt(Math.pow(cateto1, 2) + Math.pow(cateto2, 2));
}
double h = calcularHipotenusa(3, 4); // 5.0

// Ejemplo 2: Generar número aleatorio en rango
public static int aleatorioEnRango(int min, int max) {
  return (int)(Math.random() * (max - min + 1)) + min;
}
int dado = aleatorioEnRango(1, 6); // Simular lanzamiento de dado

// Ejemplo 3: Calcular área de círculo
public static double areaCirculo(double radio) {
  return Math.PI * Math.pow(radio, 2);
}
double area = areaCirculo(5); // 78.53981633974483

// Ejemplo 4: Redondear a decimales específicos
public static double redondear(double valor, int decimales) {
  double factor = Math.pow(10, decimales);
  return Math.round(valor * factor) / factor;
}
double precio = redondear(19.9567, 2); // 19.96
Nota importante:
Todos los métodos de la clase Math son estáticos, por lo que se acceden directamente con Math.nombreMetodo() sin necesidad de crear una instancia.

17. ¿Qué es un GUI (Interfaz Gráfica de Usuario)?

GUI significa Graphical User Interface (Interfaz Gráfica de Usuario). Es un sistema de interacción visual que permite al usuario comunicarse con el programa mediante elementos gráficos como ventanas, botones, menús, etc.

Componentes comunes de un GUI:

  • Ventanas (Windows/Frames): Contenedor principal de la aplicación
  • Botones (Buttons): Para ejecutar acciones
  • Campos de texto (TextFields): Para entrada de datos
  • Etiquetas (Labels): Para mostrar texto
  • Menús (Menus): Para organizar opciones
  • Listas (Lists): Para mostrar elementos seleccionables
  • Casillas de verificación (CheckBoxes): Opciones múltiples
  • Botones de radio (RadioButtons): Opciones excluyentes

Bibliotecas GUI en Java:

1. Swing (más usado):

import javax.swing.*;

public class VentanaSimple {
  public static void main(String[] args) {
    // Crear ventana
    JFrame ventana = new JFrame("Mi Primera Ventana");
    ventana.setSize(400, 300);
    ventana.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);

         // Crear botón
    JButton boton = new JButton("¡Haz clic!");
    boton.addActionListener(e -> {
      JOptionPane.showMessageDialog(null, "¡Botón presionado!");
    });

         // Agregar botón a la ventana
    ventana.add(boton);
    ventana.setVisible(true);
  }
}

2. JavaFX (moderno):

import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.Button;
import javafx.scene.layout.StackPane;
import javafx.stage.Stage;

public class MiApp extends Application {
  @Override
  public void start(Stage primaryStage) {
    Button btn = new Button("Haz clic");
    btn.setOnAction(e -> System.out.println("¡Hola!"));

         StackPane root = new StackPane();
    root.getChildren().add(btn);

         Scene scene = new Scene(root, 300, 250);
    primaryStage.setTitle("Mi App JavaFX");
    primaryStage.setScene(scene);
    primaryStage.show();
  }
}
Ventajas de GUI:
✓ Más intuitivo para el usuario
✓ Mejor experiencia de usuario
✓ Más profesional
✓ Fácil de usar (no requiere comandos)

vs CLI (Command Line Interface):
• CLI: Solo texto y comandos (como la consola)
• GUI: Visual, con mouse e interacción gráfica

18. Formas de Mostrar un Mensaje

En Java existen varias formas de mostrar mensajes al usuario, dependiendo del contexto (consola o GUI).

1. En Consola (CLI):

// a) System.out.println() - Imprime con salto de línea
System.out.println("Hola, mundo!");
System.out.println("Segunda línea");
// Salida:
// Hola, mundo!
// Segunda línea

// b) System.out.print() - Imprime SIN salto de línea
System.out.print("Hola ");
System.out.print("mundo");
// Salida: Hola mundo

// c) System.out.printf() - Imprime con formato
String nombre = "Juan";
int edad = 25;
System.out.printf("Mi nombre es %s y tengo %d años%n", nombre, edad);
// Salida: Mi nombre es Juan y tengo 25 años

// d) System.err.println() - Para mensajes de error
System.err.println("¡Error crítico!");

// e) Formato con String.format()
String mensaje = String.format("Total: $%.2f", 19.99);
System.out.println(mensaje); // Total: $19.99

19. ¿Qué es un .jar?

.jar significa Java ARchive (Archivo Java). Es un formato de archivo que empaqueta múltiples archivos Java en un solo archivo comprimido.

¿Qué contiene un archivo .jar?

  • Archivos .class compilados
  • Recursos (imágenes, sonidos, archivos de configuración)
  • Bibliotecas y dependencias
  • Archivo MANIFEST.MF (metadatos del jar)

Tipos de archivos .jar:

1. Biblioteca (Library JAR):

Contiene clases que pueden ser usadas por otros programas.

Ejemplos: mysql-connector.jar, gson.jar, apache-commons.jar

2. Ejecutable (Executable JAR):

Puede ejecutarse directamente como una aplicación.

// Para ejecutar un jar:
java -jar mi-aplicacion.jar

Cómo crear un archivo .jar:

Opción 1: Desde línea de comandos:

// Crear un jar
jar cvf mi-archivo.jar *.class

// Crear jar ejecutable
jar cvfe mi-app.jar ClasePrincipal *.class

// Ver contenido de un jar
jar tf mi-archivo.jar

// Extraer un jar
jar xf mi-archivo.jar

Opción 2: Desde NetBeans:

  1. Click derecho en el proyecto
  2. Seleccionar "Clean and Build"
  3. El .jar se genera en la carpeta dist/

Opción 3: Desde IntelliJ IDEA:

  1. File → Project Structure → Artifacts
  2. Click en "+" → JAR → From modules with dependencies
  3. Seleccionar clase principal
  4. Build → Build Artifacts

Estructura del archivo MANIFEST.MF:

Manifest-Version: 1.0
Main-Class: com.miapp.Principal
Class-Path: libs/mysql-connector.jar libs/gson.jar
Created-By: 17.0.1 (Oracle Corporation)

Ventajas de los archivos .jar:

Beneficios:
✓ Portabilidad: Un solo archivo para distribuir
✓ Compresión: Reduce el tamaño de los archivos
✓ Organización: Agrupa archivos relacionados
✓ Seguridad: Puede incluir firmas digitales
✓ Facilidad: Fácil de distribuir y ejecutar
✓ Reutilización: Las bibliotecas pueden usarse en múltiples proyectos

Ejemplo de uso:

// Incluir una biblioteca .jar en el proyecto:
// 1. Copiar el .jar a una carpeta "libs"
// 2. En NetBeans: Click derecho en Libraries → Add JAR/Folder
// 3. Seleccionar el .jar
// 4. Ahora puedes importar y usar las clases:

import com.google.gson.Gson; // De gson.jar
import java.sql.*; // De mysql-connector.jar

public class MiApp {
  public static void main(String[] args) {
    Gson gson = new Gson();
    // Usar las clases de la biblioteca
  }
}
Nota: Los archivos .jar son similares a los .zip, pero específicamente diseñados para Java. Incluso puedes abrirlos con un programa de descompresión como WinRAR o 7-Zip para ver su contenido.
